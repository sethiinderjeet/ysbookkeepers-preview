# YS Tax & Advisory – website source

Static website generated by Python. Green brand palette (`00. Color Palette.docx`), Outfit and Plus Jakarta Sans fonts.

## Edit and build
| What | Where |
| --- | --- |
| Copy, services, professions, industries, pricing, contact details, form limits | `content.py` |
| Page layouts | `pages.py` |
| Shared header, menus, footer, contact cards (.vcf) | `build.py` |
| Blog posts | SQLite via `blogstore.py` (written by the blog admin in `../ysblog-admin`) |
| Privacy Policy, Terms of Service | `legal/*.html` |
| Styles, menus, forms in the browser | `assets/css/styles.css`, `assets/js/main.js` |

```bash
python3 build.py                                  # writes pages next to this file
YS_SITE_OUT=/home/<user>/public_html python3 build.py   # production: write into the web root
```
Blog data is read from `$YS_DATA_DIR/blog.db` (default `../ysblog-data/blog.db`), which must stay outside the web root.

Upload to the web root: the generated `.html` files, `assets/` and nothing else (not `*.py`, `legal/`, `README.md`).
Links are root-relative (`/services/...`).

## Related folders
- `../ysblog-admin` – private blog admin at `/admin` and the website form mailer (Flask). Setup: its README.
- `../ysforms` – GoDaddy entry point for the form mailer at `/forms`.
